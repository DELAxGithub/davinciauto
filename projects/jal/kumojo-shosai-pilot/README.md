# 雲上書斎｜パイロット版

Generated by `video_pipeline.workflows.narrated_vtr`.

## Project Entry

Use the phase runner from the repo root:

```bash
python3 -m video_pipeline.workflows.run_narrated_vtr \
  --config projects/jal/kumojo-shosai-pilot/project.yaml \
  script-review
```

The runner intentionally has no all-in-one phase. For JAL production, narration
scripts are expected to go through editorial and fact-check review before TTS.

Recommended order:

1. `script-review`
2. revise `inputs/script.md` and `inputs/pronunciation_rules.csv`
3. `build-artifacts`
4. `pronunciation-review`
5. `tts`
6. `recalc`
7. `resolve-dry-run`
8. `resolve-apply`
9. manual subtitle import / picture edit
10. `qc`
11. `render-job`

## Outputs

- `outputs/script_review/script_review.md`: pre-TTS script structure and length review
- `outputs/ir/project_ir.json`: common project IR
- `outputs/narration/narration.md`: narration text for review
- `outputs/tts/gemini_tts.yaml`: Gemini TTS input
- `outputs/subtitles/draft.srt`: draft subtitles with estimated timing
- `outputs/subtitles/timecoded.srt`: subtitles aligned to generated narration
- `outputs/bgm/bgm_plan.csv`: reviewable BGM cue plan; all cues start as `approved=no`
- `outputs/bgm/bgm_plan.actual.csv`: selected BGM cues aligned to generated narration
- `outputs/resolve/resolve_apply_plan.json`: non-mutating Resolve plan stub
- `outputs/qc/qc_report.md`: latest Resolve timeline QC summary
- `outputs/qc/timeline_items.csv`: timeline clip inventory
- `assets/asset_log.csv`: Resolve media pool asset log

## Current Manual Gates

1. Visual review of selected Storyblocks footage.
2. Subtitle styling and any manual line-break polish inside Resolve.
3. Final BGM rights/editorial approval.
4. Start the queued review render after confirming the open Resolve timeline.

## Automated After Picture Edit

The generic narrated VTR pipeline can now regenerate QC and asset logs from the
open Resolve timeline after footage has been placed by hand. It can also prepare
a review render queue job; actual rendering stays manual.
