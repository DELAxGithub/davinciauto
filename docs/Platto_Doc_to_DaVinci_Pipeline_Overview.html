SCRIPT-DRIVEN EDITING AUTOMATION

台本があれば、荒編まで自動で進められる。

収録書き起こしや色分け台本から、使い所の抽出、尺計算、ブロック配置、DaVinciの荒編タイムライン作成までをつなぐ編集自動化システムです。 人間は「何を使うか」を決め、機械は「探す・並べる・色を付ける・尺を出す」を担当します。

導入すると変わること

台本→荒編 機械的な配置作業を自動化
尺確認 編集前に想定尺を見える化
色分け 台本のブロックをタイムラインへ反映
修正反映 Docを直して次版を生成

従来編集と導入後

番組編集の基本は、探す、切る、並べる、聴く、直す。台本があるなら、その前半の機械作業を自動化できます。

工程 従来編集 導入後
素材を探す DaVinci上で探す 台本から自動抽出
使う箇所を切る 手で切り出す 範囲指定から自動配置
台本順に並べる 手で並べる 荒編タイムラインを生成
尺を見る 並べてから確認 台本段階で計算
構成を見る 目視と記憶で追う 色分けと対応表で追う
修正する タイムラインを直接直す 台本を直して再生成
時間の使い方 探す・切る・並べるに時間を使う 聴く・判断する・仕上げるに時間を使う

作業画面のイメージ

台本上の色分けを、DaVinciのクリップ色として反映します。まずブロック単位で流れを見て、最後に必要な箇所だけ細かく切ります。

  • Pink: 導入、反応を見るブロック
  • Orange: 代理戦争、背景説明
  • Violet: 核になる論点
  • Teal: 雑談、息継ぎ、転換
  • Blue: 具体例、制度、山場

運用ルール

  • DaVinciを直接直す前に、まずDoc/CSVを直す。
  • 台本が固まるまでは、尺計算レポートを回す。
  • 最初の荒編は、行単位ではなくブロック単位で見る。
  • 細かいフィラー処理は、構成が見えてから行う。
  • 元タイムラインは壊さず、必ず別タイムラインを作る。

成果物

  • 初稿想定尺レポート
  • ブロック色分け計画
  • DaVinci荒編タイムライン
  • 元TCと完成TCの対応表
  • v2/v3へ更新できる再実行手順

まず1本で試す

まずは1本の番組で、既存のGoogle Doc/CSVとDaVinciプロジェクトを使って試します。 初回は「尺計算」と「ブロック色分け荒編」までを目標にし、次にナレーション込みの再計算タイムラインへ進みます。

初回セットアップ

  • Google Doc / CSVの列を確認
  • 元タイムラインと素材名を確認
  • 目標尺を設定
  • 色分け台本があればPDFを用意
  • 別タイムライン名で試作
